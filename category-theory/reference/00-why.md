**한 줄**: 범주론은 **합성(composition)이 성립하기 위한 최소 조건**을 다루는 이론이다.

**왜 이 이름인가**
"category"는 아리스토텔레스의 범주(사물의 분류)와는 **관계가 거의 없다.**
1945년 Eilenberg–Mac Lane이 대수적 위상수학에서 "이 구성은 저 구성과 같은 모양이다"를
정확히 말하려고 만들었다. 즉 **분류하려고 만든 게 아니라, 옮기려고 만들었다.**
→ 그래서 이 이론의 주인공은 대상이 아니라 **화살표**다. 이름이 오해를 부른다.

**TS에서는**
합성이 우리가 복잡도를 이기는 유일한 도구라는 사실이 그대로 대응한다.

```ts
const compose = <A, B, C>(g: (b: B) => C, f: (a: A) => B) => (a: A): C => g(f(a));
```

이 한 줄이 성립한다는 것 — `A → B`와 `B → C`를 붙이면 `A → C`가 **반드시 나온다**는 것 —
이 범주의 전부다.

**흔히 막히는 지점 ① — "그래서 뭘 얻는데?"**

"합성? 그거 원래 되잖아"에서 멈추기 쉽다. 얻는 게 안 보이는 것이다. 답 세 가지:

1. **합성이 안 되는 것들을 되게 만드는 게 진짜 주제다.**
   `A → Maybe<B>` 와 `B → Maybe<C>` 는 그냥은 안 붙는다. 붙이려고 만든 게 모나드다.
   즉 모나드는 "어려운 개념"이 아니라 **합성 실패에 대한 처방**이다.
2. **"무엇이냐" 대신 "무엇과 어떻게 연결되냐"로 정의하는 습관을 준다.**
   곱을 "튜플"이라 정의하면 구현에 묶인다. 보편성질로 정의하면 구현이 뭐든 상관없어진다.
   이건 인터페이스 설계 감각과 정확히 같은 것이다.
3. **절반은 공짜다 (쌍대성).** 화살표를 뒤집으면 정리가 하나 더 생긴다.

**흔히 막히는 지점 ② — 대상 안을 못 본다**
"집합 A의 원소 x를 잡자"가 범주론에선 **반칙**이다. 원소라는 개념 자체가 없다.
필요하면 `1 → A` 라는 화살표로 표현한다.
쓸데없는 금욕처럼 보이지만, 이 제약 덕분에 **집합이 아닌 것들**(순서집합,
타입, 위상공간, 프로그램)에 같은 말이 그대로 적용된다. 제약이 일반성의 대가다.

**더 볼 키워드**: Eilenberg–Mac Lane · abstract nonsense(범주론의 별명) ·
보편성질(universal property) · 쌍대성(duality) · Curry–Howard 대응
