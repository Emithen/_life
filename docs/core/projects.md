# /core 프로젝트 목록

`/core`가 설명할 수 있는 프로젝트들. 새 프로젝트를 만들면 여기에 한 줄 추가하고 폴더를 만든다.

| 키 | 프로젝트 | 한 줄 | 문서 |
|---|---|---|---|
| `youtube-feed` | 유튜브 정보 수집기 | 관심 채널 최신 영상을 모아 폰에서 보는 정적 사이트 (+개인화) | `youtube-feed/` |
| `claude-code-mastery` | Claude Code 숙련 트랙 | agent coding을 바닥부터 쌓는 학습 트랙 (youtube-feed와 병행) | `claude-code-mastery/` |
| `category-theory` | 범주론 학습 트랙 | 프로그래머 각도로 요네다까지 완주하는 개념 트랙 (TypeScript로 법칙 확인) | `category-theory/` |

## 문서 작성 규칙

- 파일마다 헤더에 **기준 커밋**을 적는다 → `/core`가 낡음을 감지할 수 있다.
- `00-overview.md`는 **그 프로젝트를 처음 보는 사람이 5분 안에 잡는 지도**. 짧게 유지한다.
- 세부는 주제별 파일로 쪼갠다. 한 번에 다 읽지 않게 하는 게 토큰 절약의 핵심.
- 코드에서 바로 읽을 수 있는 사실(함수 시그니처 등)보다 **"왜 이렇게 했나"**를 우선한다.
  코드는 읽으면 알지만, 판단의 이유는 문서에만 남는다.
