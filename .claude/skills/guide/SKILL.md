# guide — 이 저장소의 스킬 안내

사용자가 "지금 뭘 시킬 수 있는지" 한눈에 보게 해준다.
목록은 **하드코딩하지 말고 매번 실제 파일에서 읽어온다.** (스킬이 추가돼도 저절로 최신)

## 절차

### 1. 스킬 목록 수집 (명령 1회)

```bash
for f in .claude/skills/*/SKILL.md claude-code-mastery/.claude/skills/*/SKILL.md; do [ -f "$f" ] && echo "--- $f" && sed -n '2,3p' "$f"; done
```

`name`과 `description`만 뽑으면 된다. 본문은 읽지 않는다(토큰 낭비).

### 2. 용도별로 묶어서 제시

- **프로젝트 이해** — `core` 등. "매번 같은 걸 묻지 않으려고" 만든 스킬.
- **말투 전환 (실습용)** — `claude-code-mastery/`의 nyang·sageuk·junggye·muhyeop.
  Claude Code 학습 트랙의 실습 산출물이라는 점을 한 줄로 밝힌다.
- 그 외 새로 생긴 스킬은 description을 보고 적절히 분류한다.

### 3. 각 항목에 보충 한 줄

description을 그대로 복붙하지 말고, **"언제 쓰면 좋은지"**를 사용자 입장에서 한 줄 덧붙인다.
예: `core` → "코어 로직이 헷갈릴 때. 프로젝트를 골라서 물어보면 된다."

### 4. 마무리

- 지금 이어서 하기 좋은 것 1~2개를 제안한다 (예: `/core youtube-feed`).
- 사용자 전역 스킬(graphify 등)은 이 저장소 전용이 아니므로, 필요할 때만 한 줄로 언급한다.

## 형식 규칙

- 표 또는 짧은 목록. **장황한 설명 금지** — 이 스킬의 목적은 "빠른 조망"이다.
- 실제로 존재하는 스킬만 나열한다. 없는 걸 지어내지 않는다.
- 아직 만들지 않은 스킬을 제안하고 싶으면 "만들 수도 있음"이라고 명확히 구분한다.
